# Content styles: first samples

`sample-posts.html` is the first set of eight sample posts in the brand, drawn as HTML at
1080 × 1350 (feed) and 1080 × 1920 (reel cover, story). Each `<section class="post">` is
one post; render with a headless browser and screenshot each `#p1`…`#p8`.

Images are read from `img/` next to the file: the Higgsfield library picks (see
`data/library.json`), a frame from the treatment-chair film, and the salon's own photos.
Fonts from `fonts/`, logos as `img/mark-gold.svg`, `img/mark-espresso.svg`,
`img/academy-gold.svg`.

Styles: The room (reel cover), Close-up explainer (cover, inside, aftercare),
This week at the Hub, First time?, Academy, Story.

The copy is sample copy. Aftercare lines need Hollie's sign-off before anything like them
is posted.
