# Photography

Drop the real photographs in here under these names and the prototype picks
them up with no other change. While a file is missing, its slot shows the
labelled placeholder instead.

| File | Slot | What it is |
| --- | --- | --- |
| `reception-portrait.jpg` | Hero arch (4:5) | Reception: the gold desk, the logo on the taupe wall, the herringbone floor |
| `reception-wide.jpg` | The Hub rail | Reception, wide: gold desk, fluted doors, herringbone |
| `salon-mirrors.jpg` | The Hub rail | The salon floor and its arched mirrors |
| `lounge-wings.jpg` | The Hub rail | The lounge, the neon wings and halo |
| `treatment-macro.jpg` | The Hub rail | A treatment close up — to be shot |
| `academy-floor.jpg` | The Hub rail | Students, models, teaching — to be shot |
| `jessica.jpg` | Team portrait (3:4) | Jessica |
| `hollie.jpg` | Team portrait (3:4) | Hollie |

Every slot is an arch that crops with `object-fit: cover`, so portrait
orientation works best; a landscape shot is fine in the rail and is cropped
to the centre. Any size — a phone photo is enough for the prototype.

The client's original logo file goes in `../logo/` as `original.png`; it is
the master for print, and the generated marks in that folder are matched
to it.
